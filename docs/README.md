# Project documentation

This directory belongs to the project made from Umbra. Add requirements, implementation plans, decisions, user research, and operational notes here as they become useful. Choose a structure that fits the product; no issue tracker or document ceremony is required.

Start by recording the product's purpose, users, first end-to-end flow, constraints, and unresolved decisions. Keep implementation plans distinct from descriptions of behavior that already works.

[`umbra/`](umbra/README.md) contains the template's shared guidance. Component architecture and development details live in the respective component directories. Record decisions at their authoritative location and link to them from project plans.
