# Site instructions

Read [the site guide](README.md) and relevant development/deployment guidance. Produce a static public website, independently hosted from the application frontend and Rust server. The website framework is a product decision.

Use configurable `PUBLIC_APP_URL` for Open App, and real release/store/support destinations. Keep copy, platform claims, downloads, and policy text consistent with the actual product. Never expose server secrets in site configuration. Root `pnpm dev:site` runs this component independently.

This directory is documentation-only until product scaffolding is requested.
